# Elevate-Labs-Task1-Data-Cleaning
Data cleaning and preprocessing using Python and Pandas

## Objective
Clean and preprocess the Netflix Movies and TV Shows dataset.

## Dataset
Netflix Movies and TV Shows dataset containing 8,807 rows and 12 columns.

## Data Cleaning Performed
- Checked for missing values.
- Handled missing values in the dataset.
- Checked for duplicate rows.
- Standardized column names to lowercase with underscores.
- Checked the data types of the columns.
- Verified the final cleaned dataset.

## Final Results
- Rows: 8,807
- Columns: 12
- Missing values: 0
- Duplicate rows: 0
